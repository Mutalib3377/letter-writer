# UK Visa Letter Writer — Learn Ready

An AI-powered tool that generates professional UK visa application letters in seconds. Built by [Learn Ready](https://learnready.co.uk), a UK immigration guidance platform.

## Features

- ✉️ **4 letter types** — Visa Cover Letter, Sponsorship Letter, Personal Statement, Travel Itinerary Letter
- 🤖 **AI-generated** — Powered by Groq (Llama 3.3 70B) for fast, high-quality output
- 🇬🇧 **British English** — Formal tone, immigration best practices baked in
- 🔒 **Secure** — API key stored as server environment variable, never exposed to the browser
- 📋 **Copy / Print / Download** — One-click export options
- 📱 **Fully responsive** — Works on mobile, tablet, and desktop

## Local Development

1. Install the Vercel CLI:
   ```bash
   npm install
   ```

2. Create a `.env.local` file (never commit this):
   ```
   GROQ_API_KEY=gsk_your_key_here
   ```

3. Run the dev server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000`

## Deploying to Vercel

1. Push this repository to GitHub.
2. Import the repo at [vercel.com/new](https://vercel.com/new).
3. Add the environment variable:
   - **Name:** `GROQ_API_KEY`
   - **Value:** your Groq API key from [console.groq.com](https://console.groq.com)
4. Click **Deploy** — done!

## Environment Variables

| Variable       | Description                              | Where to get it            |
|----------------|------------------------------------------|---------------------------|
| `GROQ_API_KEY` | Your Groq API key (starts with `gsk_...`) | [console.groq.com](https://console.groq.com) |
